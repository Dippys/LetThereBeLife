# Open Questions and Future Systems

## Physical scale

Decide:

- Tile size in meters.
- typical walking speed.
- building footprint.
- settlement spacing.
- continent size.
- travel time.
- visibility range.

A million tiles means very different things at one meter versus ten meters per tile.

## Concept representation

Possible levels:

1. Shared engine concepts with personal signal mappings.
2. Personal confidence and category prototypes.
3. Culturally different category boundaries.
4. Fully emergent feature-based concepts.

Start simple and evolve carefully.

## Grammar complexity

Questions:

- How many semantic roles?
- How are tense, location, ownership, number, and certainty represented?
- Can constructions nest?
- How much productive grammar is required?
- When should writing emerge?

Do not solve all human linguistics initially.

## Conscious thought model

Define what counts as a "thought":

- Triggered decision.
- belief update.
- memory recall.
- emotional reaction.
- planning step.
- communication interpretation.

The definition affects performance targets.

## Forgetting policy

Questions:

- What information is never forgotten?
- How does trauma alter retention?
- How do age and intelligence affect consolidation?
- How does repeated rumor become semantic memory?
- Can memories become distorted?

## Common-language compression

Determine how to compress widespread language knowledge without turning it into automatic magical understanding.

Possible mechanisms:

- Learned familiarity bitsets.
- Community template plus individual delta.
- Household template plus individual delta.
- Age/cohort templates.
- Explicit exposure counters.

## Population hardware target

Specify:

- Minimum machine.
- Recommended RAM.
- CPU cores.
- storage.
- simulation speed.
- number of loaded chunks.
- target events per second.

Ten million persistent NPCs on 64 GB is much harder than on 128 GB.

## Multiplayer or distributed simulation

Future options:

- Dedicated headless server.
- regions distributed across processes.
- deterministic message boundaries.
- local viewer clients.
- server-authoritative time.

Distribution should not be attempted before single-machine correctness.

## Ecology

Potential systems:

- Seasons.
- animal populations.
- predators.
- crop cycles.
- fire.
- disease.
- soil depletion.
- climate variation.
- resource regeneration.

Ecology can dominate event volume and must also be event-driven.

## Institutions

Future mechanisms:

- Schools.
- markets.
- courts.
- armies.
- temples.
- taxation.
- records.
- writing.
- currency.
- government.
- slavery or coerced labor if the setting requires difficult historical systems.

## Historical presentation

Possible player-facing tools:

- Family trees.
- biographies.
- maps by era.
- language family trees.
- migration maps.
- war timelines.
- inventions.
- famous misunderstandings.
- legal history.
- settlement growth.

## Modding

Possible data-driven layers:

- Concepts.
- resources.
- terrain.
- occupations.
- action templates.
- cultural priors.
- event rules.
- UI.
- generator parameters.

Core communication privacy invariants should not be modifiable accidentally.
