# Writable Documentation Routing

| Change | Update |
|---|---|
| Implemented behavior or known limitation | `Documentation/CURRENT_IMPLEMENTATION.md` |
| Ownership, API, data flow, invariant, dependency | `Documentation/ARCHITECTURE.md` |
| Durable technical choice | `Documentation/ARCHITECTURE_DECISIONS.md` |
| Completed, active, next, deferred, or open work | `Documentation/ROADMAP.md` |
| Test coverage, command, benchmark, or validation gap | `Documentation/TESTING.md` |
| Runtime cost, type size, allocation, memory, throughput, or optimization budget | `Documentation/PERFORMANCE.md` |
| User setup, run command, or control | Root `README.md` |
| Documentation set changes | `Documentation/README.md` |

Use `InitialDocumentation/` only as immutable design input.
