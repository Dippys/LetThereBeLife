# Maintain Let There Be Life

Coordinate the repository lifecycle. Delegate detailed rules to focused repository skills instead of duplicating them here.

## Workflow

1. Apply `$orient-let-there-be-life` to map the request to code, design input, living documentation, and tests.
2. Apply `$implement-rust-engine` for Rust or Cargo changes.
3. Apply `$maintain-living-docs` for every behavior, boundary, dependency, status, test, control, or setup change.
4. Apply `$review-engine-quality` after non-trivial implementation.
5. Apply `$validate-rust-workspace` before claiming completion.
6. Apply `$evolve-repository-skills` only when a reusable workflow gap is demonstrated.
7. Report code, documentation, review findings, and validation separately.

## Guardrails

- Never modify any path under `InitialDocumentation/`.
- Do not bypass a focused skill's stricter requirements.
- Do not claim completion while documentation, review, or validation is incomplete.
